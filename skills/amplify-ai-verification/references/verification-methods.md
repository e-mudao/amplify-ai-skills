# 核验方法

按主张选工具与材料。工具能力、访问权限和用户给定范围优先；不要求每条主张都联网或同时使用多种工具。

| 主张类型 | 优先核验方式 | 容易漏掉的边界 |
| --- | --- | --- |
| 事实、制度、产品状态 | 查适用的官方文件、原始记录或可靠报道，核对发布时间与生效时间 | 新闻发布日期不等于事件发生时间；旧版本不代表当前状态 |
| 研究、医疗、因果 | 核对原研究的设计与结果，必要时看综述或指南及相反结果 | 对照组、样本、结局指标、随访期、因果识别与适用人群 |
| 数字、统计 | 找原始表格或数据定义，核对分母、单位、时间窗，用计算器或代码复算 | 百分比与百分点、绝对与相对变化、现价与不变价、四舍五入 |
| 文献、引文、链接 | 实际打开或读取目标，核对标题、作者、版本与相关段落 | 链接可访问只证明页面存在；引文存在也未必支持原句 |
| 代码与运行结果 | 读取相关实现，运行适当测试或最小复现，查看输出 | 测试通过只覆盖测试范围；静态检查不等于运行成功 |
| 数学、逻辑、比较 | 重新推导，检查定义、前提、反例与比较口径，必要时用代码复算 | 必要条件与充分条件、比较基准、遗漏变量 |
| 预测、价值判断 | 核对可检验的前提、方法、评价标准与适用条件 | 未来结果未发生，偏好本身无需事实判定 |

检索时用主体、指标、地域、年份和限定条件构成中立查询，必要时检索可能推翻结论的材料。证据不足或冲突时再调整查询；新一轮检索须针对具体缺口。对重复转载、无关页面和无法访问的内容及时停止，不以搜索量代替证据质量。

每项重要结论的最小记录是：原主张、核验方法、实际读取的来源位置或运行命令及结果、证据所支持的范围、判定、未解决的限制。所给材料之外的事实若未核实，须分开标记。用户只要快速判断时，正文保留判定、最关键证据和限制即可。
