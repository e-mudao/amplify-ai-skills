# 有界探索：将心理学启发转成控制动作

| 启发 | 可观察动作 | 停止条件 |
|---|---|---|
| 明确且困难的目标 | 写目标与判定规则；量化改善目标先确定基线，目标值标来源 | 目标不可检验则重写 |
| 不因陌生而放弃 | 寻找能区分竞争解释的可获得证据与替代方法；需要实际干预来判断效果时，再设计最小可逆试验 | 证据否证、权限不足或预算耗尽 |
| 允许失败 | 输出失败结果、反例与剩余缺口 | 禁止改指标伪装通过 |
| 跨领域探索 | 写迁移方法如何改善结果 | 无增量则删去 |

数字、期限须来自用户或标为建议，不是承诺。不要用“必然可解”压制不确定性。可行性未知不代表必须放弃，也不代表可以宣称成功。

历史故事或成功先例不是必填项；需要时核实来源和条件可比性。不能把故事直接当心理学因果证据。编译阶段修复候选最多一次。涉及工具、迭代试验或持续执行时，在交接提示词中写明资源上限与停止条件；未设预算可建议有界试验。简单文本或创作任务用完成标准即可。
