# Depth：增加证据强度

用四问发现关键缺口：专家补做什么、原始材料是什么、方法为何适用、外部证据是什么。只把改变方案的结论写入提示词，不要求逐项展示。以最简单但充分的方法开始；SQL、统计模型或模拟器不能仅为显得专业而引入。

材料优先：原始事件/交易/代码/原文 → 系统导出 → 汇总表 → 口头摘要。低等级材料可以支持有限结论，标明损失，不强制索取所有数据。

挑战一个关键假设，给可推翻它的观察。需要判断量化改善且缺少基线时先测量；解释命题时，用竞争解释、反例与已有证据检验机制。明确区分：

- 描述：样本中发生了什么。
- 预测：未见样本上能否预测；按时间或实体划分，避免泄漏。
- 因果：改变因素是否改变结果；须有识别策略及其假设，不能由相关性或 AUC 推出。

新增发现须说明反例、适用范围和后续复核。结构自检可由模型完成，事实正确与业务收益必须由可追溯材料、独立标准或实际试验支持。模型生成的测试通过只证明其覆盖的性质。
