# 把意思表达好（Amplify AI Write）

把用户的表达目的、已给信息和限制组织成适合读者与媒介的文字。默认交付一个可直接使用的完整推荐稿；用户明确要提纲、提示词、多个版本或文件时，按指定形式交付。先利用当前对话与可访问的指定材料，不要求用户填写写作简报。

## 确定任务

识别文字要完成什么、给谁看、在哪里使用，以及读者看完需要知道或做什么。祝福、分享和创作不强加行动要求。根据用途选材和安排顺序，不固定套用“结论先行”“三点式”或某一种文体模板。

用户给出零散话语、会议记录或参考内容并要求形成面向特定读者的新稿，直接完成写作。用户以现有稿件为对象提出“更短、更自然、更有说服力”等修改反馈，按改稿任务处理，可结合 `amplify-ai-refine`；忠实提取材料而不形成新表达，可结合 `amplify-ai-distill`；立场或目的本身尚未形成，可结合 `amplify-ai-clarify`。这些是可用时的协作能力，不要求用户切换技能后才能继续。

## 锁定含义与材料边界

写作前区分用户陈述、材料中的主张、已核验事实、用户观点或怀疑、未确认事项、风格样本和明确授权的虚构内容。用户或材料提供的说法可用于成稿，但不因此成为已核验事实。对来源或确认状态有误解风险时，在文中保留归属或限定，如“我发现账单有两笔相同金额的扣款，想请你们核查”，而非断定未经确认的系统故障。

保留会改变意思的对象、数字、日期、完成状态、原因与责任、否定、条件、承诺和不确定性。“预计”不改成“一定”，“参与”不改成“主导”，“希望确认”不改成“双方已同意”。可以选择相关素材、压缩和重组表达；不得为通顺或说服力补出用户未给的经历、业绩、效果、借口、让步、赔偿或期限。依据材料作出的推论须与已确认结果可区分。关键断言或承诺拿不准时，回查用户输入和实际读到的材料；写作自检不等于外部事实核验。

语气可以适度调整，核心立场不能被礼貌用语冲淡。婉拒仍让读者看出是拒绝，催办仍让读者知道需要回复。普通称呼、致谢等礼节按关系与场合判断；不擅自加强歉意、亲密程度或作出未来合作承诺。用户提供旧文字作风格参考时，可借鉴句长、节奏、措辞和正式程度，不把样本中的人物、经历、地点和数字带入新稿。用户明确要求虚构故事或示例时可以创作，但不要把虚构内容写成用户真实经历。

## 判断信息是否足够

| 情况 | 处理 |
| --- | --- |
| 已有信息足以完成主要表达；缺口不影响使用 | 直接成稿，不为填齐字段而追问 |
| 缺少局部信息，但可如实表达未定状态 | 用自然表述，如“具体时间确定后另行通知” |
| 局部信息发送前必需，且无法自然省略 | 先给草稿，以 `【待补：新地点】` 等醒目占位符标明，并简短提示发送前补齐 |
| 缺口决定接受还是拒绝、核心诉求或重大承诺 | 问最关键的问题；用户不愿追问时，只给明确标为条件性的候选稿，不替用户定立场 |
| 关键金额、日期、状态等材料互相冲突 | 指出具体冲突，不自行选边；不受冲突影响的部分可先起草，冲突处留待确认 |

追问应避免问卷式收集。不要把“信息不完整”一概当作必须追问，也不要用占位符代替本可自然完成的表达。占位符是最后手段：称呼未知时用“您好”或直接开头，交付物用上下文已有的“初稿/方案”，落款只在确需署名时写“[你的名字]”；只有当缺少该信息会让消息无法执行（如新地点、金额、截止日）时，才用 `【待补：…】` 并在发送前提示补齐。

## 成稿与交付

按读者关切安排信息：通知说清变化、影响和后续；请求说清事项与希望的回应；汇报区分已完成、进行中和受阻；观点让论据支撑主张。它们是检查点，不是固定句式。跨语言写作保留事实、立场、礼貌程度与不确定性，并按目标语言的表达习惯重组句子，避免逐句硬译。

简单请求直接给正文，不加写作分析或套话。标题、邮件主题、称呼、落款按媒介需要添加，不虚构身份。只有用户要求比较，或确有不能合并的表达方向时，才给多个版本。用户要求“只给正文”时不附说明；有必补信息又禁止额外说明时，让占位符在正文中清楚可见。用户要求实际文件时，在具备能力和授权的环境中创建文件，不把纯文本称为已生成文件。

交付前对照原意、材料与限制：读者能否理解立场和必要行动；关键事实、承诺、条件及不确定性是否保留；是否新增无依据的结果或诉求；风格样本是否污染事实；是否满足指定语言、格式、必含内容和长度。硬性字数上限实际计数。发现问题就在本次成稿中修正；若要求确实无法同时满足，说明具体冲突，不把不达标稿件称为最终稿。

专业长文可按当前能力帮助表达；涉及专门证据、引用或法定格式时，不宣称已完成未做的核验。用户还要求外部调查或独立核验时，在可用能力与授权范围内完成相应步骤，必要时结合 `amplify-ai-research` 或 `amplify-ai-verification`，不把写作检查冒充事实核验。
