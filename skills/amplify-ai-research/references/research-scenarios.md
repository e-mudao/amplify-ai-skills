# 研究场景

只读相关场景。以下指导按主张和用途选用，不是每题必做清单。

## 政策与规则查询

先确认规则所辖地区、对象、版本和查询时点。信息已在上下文中就不重复问；缺地区且直接影响金额或资格时，先问地区。查现行正式文件、修订与废止信息、主管机构的当前办事指南；公开解读用于解释，不能凭旧攻略认定当前有效。

把“文件存在”“已生效”“仍在受理”“用户符合条件”“有剩余额度”“实际获批”分开。只知道时间窗口时给条件性答案，个人资格、动态余额未查实就保持未知。拟议文件、征求意见稿和旧文件要注明性质，不冒充现行规则。

例：办法写“10月至12月受理、限本市居民、额度用完即止”。查询时处于11月，只支持仍在规定时间窗口；若没有身份和余额证据，不能回答“你现在一定能领到”。页面11月更新也不能补足这两项证据。

用户要了解规则时，回答规则及重要限制即可；申请入口、材料清单或操作流程仅在服务本次用途时补充。研究不自动提交申请，不从规则一般资格编造个案认定。

## 产品与服务比较

锁定型号、地区、代际、容量或套餐。只在歧义会改变主要结论且无法合理处理时追问。按用途选择有区分力的维度，区分官方规格、独立测试、用户反馈和评价建议。

| 易错点 | 正确处理 |
| --- | --- |
| “行业第一” | 追查排名对象、指标、时间、样本和发布方；销量第一不证明性能第一 |
| 宣称效果 | 检查测试标准、工况、样本与利益关系；标称参数和实际使用表现分别写 |
| 不同市场价格 | 注明币种、税费、地区、版本与报价时点；无可靠转换条件不直接排便宜顺序 |
| 缺失字段 | 区分明确不支持、不适用、未搜集、未能读取、未公布及未验证；只有证据表明确未公布才这样写 |
| 售后更好 | 条款年限、适用部件、排除条件和实际服务体验分别判断，不能只以年限概括总体 |

统一表格可保留不可比项，不为齐全补值。建议明确采用的价格、性能、维护成本或其他标准；个人偏好未给时可说“按这些标准更合适”，不能声称已选出用户最佳方案。

经济性分析明确模型边界：设备和安装成本、实际可用电量、往返效率、价差、循环及退化、维护、政策和备电价值。没有用户数据可以给条件框架；不编造本地电价、个人预算、停电频率或具体回本年限。

## 一般专题、科学效果与争议

围绕主问题组织必要背景、证据与条件，避免百科式铺陈。用中性表达检索；对倾向性提问先确认可检验命题，寻找能够改变判断的反例和竞争解释，不为“正反都要”凑薄弱材料。

总体效果问题可优先适用且方法可靠的系统综述或指南；具体机制、研究细节或新发现再看原始研究。二手性质本身不使综合证据弱于单一案例；同时检查综述质量、纳入时间和共同原始数据。

比较结果要保留行业、人群、干预强度、总工时、观察期和指标。满意度改善不等于产量改善；相关不等于因果；无统计显著差异不等于证明完全无效。提出机制或预测时标明前提和尚缺的验证。

用户问“为什么X已发生”，先确认X；被证据反驳则纠正，只有传闻则保持未决。明确假设下的推演按假设给可能影响，不转成无关真实性调查。

专业研究说明实际材料与方法范围，不把快速资料检索命名为完整系统综述或正式尽调。资料不足时给目前可支持的结论与会改变判断的缺口，避免套用无关的长篇免责声明。

## 来源清单、计划和提示词

用户要来源清单时，按研究问题说明每份来源用于支持或检验什么，附实际访问到的定位信息；只有搜索发现时标明待核，不虚构读后评价。

用户只要计划或清单模板时，来源类别、关键问题、预计方法和完成判据即可，不能编造真实引用或已完成结果。提示词包括目标、范围、必要输入、来源约束、输出及成功标准；保留“现在不研究”等指令对本轮的作用，不误写成下游永远不能研究。接收环境无法访问的材料注明需附带，不使用“同上”掩盖依赖。
