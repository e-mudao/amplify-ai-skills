# 证据与综合

按实际问题选择小节。目的在于判断某来源支持什么、还差什么，不给来源机械打总分。

## 来源、主张与独立性

先保留原主张的主体、量词、时间、人群、条件和指标，再检查材料是否真正支持它。主题相关、有人声称、存在一个案例，分别不同于证明普遍事实。

| 来源能支持什么 | 仍需检查 |
| --- | --- |
| 正式文件写了什么、何时适用 | 是否修订废止、辖区和对象是否适用、是否需要配套文件 |
| 厂商公布的规格或服务条款 | 型号、地区与版本；标称值不能替代实际表现 |
| 当事方作出某项声明 | 声明内容是否获其他证据支持；无回应资料不等于没有回应 |
| 方法透明的测试观察 | 工况、样本、测量误差与实际用途是否匹配 |
| 系统综述、指南或原始研究 | 方法质量、资料时段、纳入对象、偏差与证据重叠；不是一律原始研究优先 |
| 用户反馈或成功故事 | 可提示故障类型和机制线索；选择偏差和无分母使其不足以估计总体发生率 |

追踪事实、数据或观察来自哪里，而不只看URL、作者或发布机构：十家媒体引用同一匿名截图，仍是一条未独立佐证的线索。综述与其纳入论文也不是两套独立实验。共同数据可能支持不同分析，但必须说明依赖关系。无法追溯时标为独立性未确认，不猜原始来源数。

## 摘要与访问范围

| 实际读到什么 | 可以怎样使用 |
| --- | --- |
| 搜索结果摘要或未打开的链接 | 用于找线索；不作已核查正文的证据 |
| 正式论文摘要 | 引用摘要明确报告的对象、观察或数字；说明对全文方法及其他细节未核查 |
| 可靠二手转述 | 归因于该报道或综述；核对引述语境，重要时明确原文未读 |
| 原文相关段落及充分上下文 | 支持该段能证明的主张；不推定全文均已审查 |

“摘要未说明对照组”意味着信息未知，不能改为“没有对照组”。无法访问原文时，可以寻找其他合法版本或适当替代证据；二手材料不能冒充一手阅读。不得从标题、URL或记忆补造细节。

用户粘贴“说明书第7页写明保修2年”，可写“据你提供的说明书摘录（第7页）”；未实际打开原件时不能写“本次已阅读说明书第7页”。材料转述的访问状态不是执行者本次工具经历。

## 时效和口径

按问题需要检查事件或统计发生期、发布日、页面更新日、生效和截止条件。为时效性结果记录实际查询日期，按宿主可靠日期和时区处理“今天、今年”。缺少可靠时点且会改变答案时说明或澄清，不编造访问日期。

查询日期在受理期内，只证明时间条件可能满足；不证明用户满足个人资格、额度仍有余额或申请一定获批。官网转载旧文不自动延长有效期，新闻中“拟实施”不能写成已经生效。旧版本可用来解释历史或变化，不用于冒充当前规则。

数字比较先检查计量单位、币种汇率、税费、分母、名义或实际值、样本及统计时段。Wh是能量，W是功率；mAh转Wh需要对应标称电压，不能猜。售价注明地区、型号、报价时点和交易条件；旧报价不能称当前成交价。无法直接比较时保留原值并说明，不伪造统一口径。

计算有必要时使用实际计算工具，保留足以复核的输入、单位、表达式和近似。以充入电量为基准计算储能收益时，购电成本按充入量计，抵用电量扣除往返损耗；毛收益不含成本不能称净收益或回本保证。

## 冲突与因果

先看两个结论是否在回答同一问题：满意度不是生产率，单位工时产量不是总产出，四天压缩工时不是减少总工时。再检查样本选择、工况、对照、测量与时间。

若一方证据更适合或更可靠，说明理由后作有界判断；没有义务给薄弱观点同等权重。无法消解的高质量分歧保留为分歧，不取平均或猜折中答案。总体估计不确定也不等于每个场景都无效果。

因果主张需检查时间顺序、对照或反事实、混杂和选择偏差、识别假设及测量。随机或准实验设计也要看实施与适用条件，不凭标签保证结论。机制只能说明可能如何发生，不能单独证明效果存在；预测准确也不等于干预有效。

## 主张判定和记录

与本系列verification使用相同含义：

| 判定 | 含义 |
| --- | --- |
| 支持 | 本次实际检查的证据支持保留限定后的原主张 |
| 部分支持 | 原主张可分解，只有明确部分有支持；说明哪部分及其余状态 |
| 反驳 | 适用证据与原主张矛盾，不只是未找到支持 |
| 证据冲突 | 相关证据之间有未解决的重要冲突 |
| 证据不足 | 当前材料和检查范围不足以判断，不等于主张为假 |

不能把“所有人被治愈”改弱为“部分人短期评分改善”后判原主张已支持；实际发现的较窄结论另写。未知、推断、建议与访问状态分别表达，不合并成一个置信度数字。

复杂任务可按以下字段追踪关键主张，简单任务直接在答案就近引用：

| 主张及必要限定 | 支持/反驳的实际内容与位置 | 日期、范围与方法 | 共同源头 | 访问状态与剩余缺口 |
| --- | --- | --- | --- | --- |

记录服务于复核和综合，不要求用户看表，也不证明事实必然正确。只持久化实际有恢复或复用价值的内容，不承诺跨会话自动记忆。
